# Profilkártya-szerkesztő

Egyszerű JavaScript-, Git- és GitHub-alapozó projekt. Az űrlap adatai egy profilkártyán jelennek meg, a felület számolja a sikeres frissítéseket, alaphelyzetbe állítható, majd külön feature branchen sötét témával bővül.

## Használat

1. Nyisd meg a mappát Visual Studio Code-ban.
2. Nyisd meg az `index.html` fájlt böngészőben, vagy használd a Live Server bővítményt.
3. A JavaScript-kódot az `app.js` fájlban írd meg.
4. A böngésző konzolját az `F12` billentyűvel nyisd meg.

Nincs telepítendő függőség és nincs buildlépés.

## Fájlok

- `index.html` – a felület szerkezete;
- `styles.css` – a kész alapmegjelenés;
- `app.js` – a tanuló által elkészítendő működés;
- `.github/pull_request_template.md` – segítség a pull request leírásához;
- `.gitignore` – helyi, nem verziókezelendő fájlok listája.

## Funkciók

- [ ] Az űrlap adatainak megjelenítése a profilkártyán
- [ ] Kötelező mezők ellenőrzése
- [ ] Sikeres frissítések számlálása
- [ ] Alapértékek visszaállítása
- [ ] Sötét téma a `feature/sotet-tema` branchen
- [ ] GitHub pull request és merge
